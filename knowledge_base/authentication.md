# Authentication and Access Management

## Token and login failures
For HTTP 401 errors, confirm that the access token has not expired and that authentication is configured correctly.

## Permission failures
For HTTP 403 errors, confirm that the user has the required role and resource permissions. Request access through the approved administrator process.

## Single Sign-On
If SSO login fails, verify the identity provider status, account assignment, and configured SAML settings. Escalate persistent failures to the identity support team.

## Security
Never share passwords, API keys, access tokens, or private credentials in support tickets or chat messages. Do not bypass authentication or access controls.
